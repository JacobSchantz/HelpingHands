# pebbles-assets

The project's own Pebbles assets, generated by `pebbles project-icon` and
committed to this repo on purpose: the Pebbles macOS app reads them straight
out of the checkout, so a fresh clone draws the right icon with nothing to
configure.

- `icon.png` — this project's app icon with the background removed, 512x512.
- `icon.json` — which source it came from, how the background was handled,
  and the SF Symbol to draw when there is no PNG.

Regenerate with `pebbles project-icon` from anywhere in the repo. It is
deterministic: an unchanged source rewrites nothing.

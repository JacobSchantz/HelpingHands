Initial import: all base finger STLs and available matching STEP files, original README, assembly addendum and license. No geometry changes. This is a finger-first source subset, not a complete hand manufacturing package.

Use OpenSCAD for local 3D work. inspect_index.scad displays one original index component, not an assembled finger. STEP sources remain available for precise CAD editing.

MIT Hand Prototype contains the separate BiDexHand reference. Aero Derived Prototype remains the separate noncommercial Aero experiment. Do not relabel either source as MIT.

Full assembled visual reference: full_hand/view_stl.scad imports full_hand/orca_v2_assembled_visual.stl. This is the official v2 description model at zero joint pose, not a verified v2.1 manufacturing assembly or a single printable solid. See full_hand/README.txt.

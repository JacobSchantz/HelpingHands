# SSH into Raspberry Pi

## Find the Pi on your network
# 1. Check ARP table for Raspberry Pi MAC prefix (dc:a6:32)
arp -a | grep -v incomplete

# 2. Ping potential Pi IPs found above
ping -c 3 <ip-address>

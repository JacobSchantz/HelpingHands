# Generalist Gripper iterations

The current review version is [Generation 8: Pollen's Grabette, exactly as published](versions/v008_pollen_grabette/README.md).
Generation 7 (the Generalist yellow fingers only) is preserved in versions/v007_generalist_fingers.
Generation 6 (dorsal drive, Generalist honeycomb fingers) is preserved in versions/v006_dorsal_drive.
Generation 5 (mirrored geared jaws) is preserved in versions/v005_mirrored_gears.
One shared parametric jaw source updates both sides, with an explicit tooth-phase
exception for the direct gear mesh. Motor fit, retention, backdrive and force
sensing remain unfinished; this is inspection CAD.

Preserved earlier versions include [Generation 4](versions/v004_symmetric_pincher/README.md)
and [Generation 3](versions/v003_single_pincher/README.md). No earlier CAD was overwritten.

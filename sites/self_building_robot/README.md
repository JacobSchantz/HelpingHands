# The robot that builds itself (site mock-up)

A one-page mock-up of `plans/self_building_robot.md` (voice-ef1a0591). Plain HTML, CSS and JS, no build step.
Every illustration is SVG drawn by `robot.js` from one parametric robot (`robot()`, `arm()`, `pliers()`).

    sites/self_building_robot/serve.sh      # http://localhost:8790  (PORT=… to change)

Add `#still` to the URL to stop the hero animation (used for screenshots).
